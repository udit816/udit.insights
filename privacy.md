# Privacy policy: Udit Insights Uploader

Last updated: 10 November 2026

## What this app is

Udit Insights Uploader is a private tool that Udit Pathak uses to upload and schedule videos on his own YouTube channel, @udit.insights (https://www.youtube.com/@udit.insights). It is not offered to the public, and no other person signs in to it.

## What data it uses

The app uses a Google sign-in token for Udit's own YouTube account, with the YouTube scope that allows uploads and video settings. It uses the video files, titles, descriptions, tags and thumbnails that Udit creates for his channel. It reads public view, like and comment counts for videos on his own channel.

## How the data is stored

The sign-in token is stored only on Udit's own computer. The app does not send it to any other service. The app does not collect, sell or share data about other people.

## Google API data

The app uses Google API data only to upload and manage videos on Udit's own channel. Its use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

## How to remove access

Access can be removed at any time in the Google Account settings under Third-party apps and services.

## Contact

Questions about this policy: send a message to the @udit.insights YouTube channel.
